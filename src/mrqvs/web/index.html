Motor de IA (qualidade Moises)

Os backends em vermelho são de inteligência artificial. Instalando um deles (demucs) a separação deixa de ser aproximada. É um download de ~1 GB e só precisa ser feito uma vez.

Prefiro instalar eu mesmo

Com Python instalado no PC, o MRQ VS usa o demucs do sistema:

winget install Python.Python.3.12
python -m pip install demucs

Depois feche e abra o MRQ VS. O painel fica verde sozinho.

Nada marcado = todos os stems que o modelo escolhido entrega.
